# Bloodlust Engine
This was an attempt at a game engine I worked on between 2025 to early 2026. It was intended to be used for 2D game development, however as time went on I realised this was stupid and that I should probably just use an established framework so I can actually work on making games instead of slowing myself down with this.

The code is provided here in case it ends up helping someone out in some form. I don't really advise building off of this; it's super messy, and a lot of it comes from when I was pretty much just starting to learn C++. There could be some interesting tidbits in there somewhere, I got no clue at this point.

There will be no further updates, fixes or even security guarantees; use at your own risk.
