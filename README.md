# Bloodlust Engine
This was an attempt at a game engine I worked on between 2025 to early 2026. It was intended to be used for 2D game development, however as time went on I realised this was stupid and that I should probably just use an established framework so I can actually work on making games instead of slowing myself down with this. The code is provided in case it ends up helping someone out in some form.
There will be no further updates, fixes or even security guarantees; use at your own risk.
